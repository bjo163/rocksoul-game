## D — Traceability contract
Each actual derivative game artifact should carry:
`source_repository`, `source_commit_sha`, `source_path`, `source_line_or_section`, `original_version`, `original_author`, `claim_type`, `source_language`, `license`, `privacy`, `transformation`, `reviewer`, `review_status`, `game_artifact_id`.
Empty source SHA is allowed for a *planning* candidate but blocks claiming a specific manuscript was fully audited. `NO_SOURCE` must be explicit for all wholly new game fiction.

## E — What we did NOT claim
We have not exhaustively downloaded all repositories, all branch histories, all private conversations, every image, song, asset or licensed translation. The above atlas is an identified, navigable **source/recovery roadmap**, not proof of complete recovery. No imported technical or editorial source becomes a live dependency merely because it appears in this table.
