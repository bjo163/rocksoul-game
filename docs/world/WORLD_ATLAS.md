# ROCKSOUL GAME — Working World Atlas
**Status:** New game adaptation proposals. Every locale in this document is a fictional game region unless labeled as a source-recovered name. No physical installation, real-world place, sacred geography, time-travel claim or real energy generator is implied.

## 1 — Navigation principle
The Moon is the symbolic witness anchor, not a literal omniscient sensor. Travel connects story evidence and playable places. Signals, lines, runaways, starlight, split identities and archives are the visual grammar. **Fog of War** means the player has not explored an area; it never means a source has been disproved.

## 3 — Narrative geography vs archival reference
The following are **research/reading lenses**, not inherently RPG locations: Jerusalem 70 CE comparative event evidence, QUR'AN/TORAH/PSALMS/GOSPELS and other corpus families, real prophets' missions, M-TIME/Antikythera, Atmosphere OS/Earth Command Center, geospatial Krakatau–Sukabumi, Cosmos/HELIOGRID and Paradise Atlas. Do not convert holy places, religious afterlife, actual disasters or personal crises into farmable combat maps.

## 4 — AETHERION: separate future game register
Historic proposal: **10 realms / 100 RPG levels**. These are not identical to **8 MOONWITNESS II eras**, **10 WINGS**, **4 AGE CODE phases**, **99 editorial chapters**, or **33 Patch themes**. Exact historical realm names, native order and rules require authoritative source recovery. Do not invent and register 10 new realm names as recovered originals.

Proposed implementation if approved: `Realm` is an optional fiction-only expansion category; can group chapters or procedural exploration maps. `Era` continues to describe story progression. `Level` is game balance only. Combat targets fictional constructed threats, never real-world peoples, sacred beings or theological classification.

## 5 — Map contract and playable scale
First slice has **one contained station scene**, not an open world: home position, generator, NPC, one interactive beacon, inspectable archive fragment, restore action and save. Region graph stores typed edge, era availability, story requirement, source/generation status, accessibility/tile navigation and future multiplayer room assignment.

Visuals: large moon, deep indigo/black with selective electric yellow, blue and pink; photocopy/grunge + manga-lines + dynamic responsive cards/typography. Prefer a readable player HUD over decorative noise; user motion and accessibility controls required.
